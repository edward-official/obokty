## 프로젝트 개요

장거리 연애를 하는 국제 커플들을 위한 웹 서비스

### 제공 기능

- 온라인 게임
  - 언어 학습 게임: 만약 대한민국-폴란드 커플의 경우를 예시로 들면, 영어로 특정 단어(window)를 보여주고 상대방의 언어(okno, 창문)로 정답 단어를 아는지 대결하며 서로의 언어를 점점 학습하는 게임.
  - 체스
  - 밸런스 게임
- 공유 앨범
  - 같은 책 읽고 독후감 쓰기
  - 데이트 사진 + 추억의 글 남기기
  - 좋아하는 음악 공유
  - 여행 추억 지도
- 비전 보드: 각자 인생의 목표와 미래를 함께 그려가는 공간
